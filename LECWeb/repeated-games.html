Repeated Games

Consider the (static) game in the strategic (normal) form: $G=(I,A,u)$.

The finitely repeated game $(\Gamma,T)$ is the game where agents play $G$ for $T$ periods; at each period they observe all the past choices; and their final payoff is the sum of period payoffs.

The infinitely repeated game $(\Gamma,\delta)$: they play $G$ in the first period, at any period if they always played $G$ in the past, they play it again and with probability $\delta$ they move to the next period and with prob. $(1-\delta)$ the game ends.

Repeated Games

Expected Payoff

In the infinitely repeated game $(\Gamma,\delta)$ the expected payoff is

$$U_i(a)=\sum_{t=0}^{+\infty}\delta^t\cdot u_i(a^t)$$

where $a^t$ is the action profile played at period $t$ if players follow the strategy profile $s$ and $\delta\in(0,1)$ is the discount factor (inverse of the interest rate) or, alternatively, $\delta$ is the probability the game will continue in the next period.

Repeated Games

Strategies

A strategy for player $i$ is a mapping from her information sets into her actions available at the info. set. Players always play the same (stage) game at every period, so the exact same set of actions, $A_i$, is available at player $i$ at any period. The set of all possible combinations of players' actions, $A=A_1\times A_2\times \cdots \times A_n$, is the set of possible outcomes of the stage game.

What are the information sets of player $i$? He or she observes the past play, so each possible history of the game, $h_t=(a^0,a^1,\ldots,a^{t-1})$ with $a^k\in A$, corresponds to an information set for the player. So the set of all information sets (histories) is:

$$\mathcal{H}=\bigcup\limits_{k=1}^\infty A^k \cup \{\emptyset\}, \text{ where }$$

$A^k=\prod\limits_{j=1}^k A$. And a strategy for player $i$ is a function $s_i:\mathcal{H}\rightarrow A_i$. That is, $s_i(h_t)$ returns the action chosen by player $i$ in period $t$ when the history $h_t$ occurs.

Main results:

  1. Any strategy that calls for players playing some Nash eq. of $G$ (possibly distinct) at every period is a SPNE of $\Gamma$.
  2. However $\Gamma$ has other SPNE that are very different from just playing a Nash eq. of $G$.
  3. For example, for high values of $\delta$ it is possible to have cooperation in the repeated prisoners dilemma as a SPNE.

Representing Strategies as Automata

Formal Definition

Formally, an automaton is $(S,\alpha,\tau)$, where:

  • $S$ is the set of states.
  • $\alpha:S\rightarrow A$ is the outcome function, it maps the set of states to the set of action profiles of the stage game.
  • $\tau: S\times A\rightarrow S$ is the transition function, at each state and given the action profile chosen (not necessarily the one dictated by the strategy), it gives the next state.
The Previous Example
Each one of the four circles denotes a state which we now shall label (from left to right): $s_1$, $s_2$, $s_3$ and $s_4$. The outcome function is $\alpha(s_1)=CC$, and $\alpha(s)=DD$ for any state $s\neq s_1$. The transition function is: $\tau(s_1,CC)=s_1$, $\tau(s_1,a)=s_2$ if $a\neq CC$, $\tau(s_2,a)=s_3$, $\tau(s_3,a)=s_4$, and $\tau(s_4,a)=s_1$ for all $a$. The transition function for states $s_2$, $s_3$, and $s_4$ is a constant function as it does not depend on the action profile chosen.

The Value Function

The value function $V:S\rightarrow \mathbb{R}$ maps states to their value. What are the players' payoff of reaching a state? Instead of computing an infinite series, the recursive approach allows us to decompose the payoff in two components: the current payoff and the discounted payoff of the future state:

$$V(s)= u(\alpha(s))+ \delta \cdot V(\tau(s,\alpha(s)))$$

Since the above equation applies to each state, we have a system of equations. Let $\#S$ be the number of states, then we have $\#S$ equations, in which the unknown variables are the values of the states: $V(s_1), V(s_2), \ldots$ Thus, if we have a finite number of states, we can solve this linear system easily.

The Value Function

Stochastic Transition

If the transition function is stochastic, the next state is not determined with certainty. Instead, $\tau(s_{t+1}|s_t,a)$ gives the probability of transitioning to state $s_{t+1}$ given the current state $s_t$ and the outcome of the game in stage $t$, $a$. The value function becomes:

$$V(s)= u(\alpha(s))+ \delta \sum_{s' \in S} V(s') \cdot \tau(s'|s,\alpha(s))$$

Since the above equation applies to each state, we again have a system of $\#S$ equations in $\#S$ unknowns: $V(s_1), V(s_2), \ldots$ The system is linear and can be solved in the same way as the deterministic case.

Testing whether a strategy is a SPNE

For every state $s$, for every player $i$, and for every action $a_{i}$, it must be the case that:

$$V_{i}(s)\ge u_{i}(\alpha_{-i}(s),a_{i})+\delta \cdot V_{i}(\tau(s,\alpha_{-i}(s),a_{i}))$$

The One-Shot Deviation Principle

Definition: A strategy $z_i$ for player $i$ is a one-shot deviation from strategy $s_i$ if there is a subgame in which the strategy $z_i$ plays a different action profile than $s_i$ does but, in all other subgames the two strategies are identical.

The One-Shot Deviation Principle
In a finite game or in a repeated game with discounting, a strategy profile is a subgame perfect Nash equilibrium, if and only if, there are no profitable one-shot deviations by any player.

Testing whether a strategy is a SPNE

Auxiliary Static Game

For every state $s$, for every player $i$, and for every action $a_{i}$, it must be the case that:

$$V_{i}(s)\ge u_{i}(\alpha_{-i}(s),a_{i})+\delta \cdot V_{i}(\tau(s,\alpha_{-i}(s),a_{i}))$$

That is, for each state $s$ we construct an auxiliary static game, $\hat\Gamma(s)$, in which players' actions are the stage game actions and payoffs are $\hat u_i(a)=u_{i}(a)+\delta \cdot V_{i}(\tau(s,a))$ and we test if $\alpha(s)$ is a Nash eq. of $\hat\Gamma(s)$.

$u_i = \ln(a_i^t)$.

The remaining stock doubles before the next period: \[s^{t+1} = 2(s^t - a_1^t - a_2^t).\]

The Memoryless Strategy

An Inefficient Outcome

Consider the following memoryless strategy:

$$a(s) = \frac{1-\delta}{2-\delta}s$$

Its automata representation is:

The stock grows at rate $\tfrac{2\delta}{2-\delta}$ — it grows without bound if $\delta \gt 2/3$, declines to extinction if $\delta \lt 2/3$.

The value function is:

$$\begin{aligned} V(s) &= (1-\delta)\sum_{t=0}^{\infty} \delta^t \ln\!\left(\dfrac{1-\delta}{2-\delta}\,s\left(\dfrac{2\delta}{2-\delta}\right)^{\!t}\right)\\ &= \ln s + \ln\!\dfrac{1-\delta}{2-\delta} + \dfrac{\delta}{1-\delta}\ln\!\dfrac{2\delta}{2-\delta}. \end{aligned}$$

Notice that the value function satisfies the following recursive equation:

$$V(s) = u(a(s)) + \delta\cdot V\bigl(2(s-2a(s))\bigr)$$

Also notice that this strategy is a subgame-perfect Nash equilibrium since it satisfies the one-shot deviation principle:

$$V(s) \geq u(a_1) + \delta\cdot V\bigl(2(s-a_1-a(s))\bigr)$$

A Cooperative Strategy

An Efficient Outcome

Consider a strategy with two phases — a cooperative phase ($c$) in which both players extract the efficient amount $a^*(s)$, and a punishment phase ($p$) in which both players revert forever to the memoryless strategy. Any deviation from $a^*$ triggers the switch to the punishment phase.

$$a^*(s) = \frac{1-\delta}{2}\,s$$

Its automata representation is:

Under the cooperative phase the stock grows at rate $2\delta$, so it grows without bound if $\delta \gt 1/2$.

The value function in the cooperative phase is:

$$\begin{aligned} V(s,c) &= (1-\delta)\sum_{t=0}^{\infty} \delta^t \ln\!\left(\dfrac{1-\delta}{2}\,s\,(2\delta)^{t}\right)\\ &= \ln s + \ln\!\dfrac{1-\delta}{2} + \dfrac{\delta}{1-\delta}\ln 2\delta. \end{aligned}$$

In the punishment phase, $V(s,p)$ coincides with the value function derived in the previous frame.

Notice that the cooperative value function satisfies the recursive equation:

$$V(s,c) = u(a^*(s)) + \delta\cdot V(2\delta s,\, c)$$

The one-shot deviation principle — checked only in the cooperative phase — requires:

$$V(s,c) \geq u(a_1) + \delta\cdot V\bigl(2(s-a_1-a^*(s)),\, p\bigr)$$

The $V$ on the right-hand side uses the punishment phase — a deviation triggers the switch. This holds for $\delta$ sufficiently large.
