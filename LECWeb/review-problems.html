Recursive utility

Consider a similar setting of PS 03. Mark Watney is stranded on Mars with 4 potatoes ($k_0=4$); the unconsumed stock doubles each period, $k_t=2(k_{t-1}-c_{t-1})$, and his period utility from consumption is $u_t=\sqrt{c_t}$. Now there are only three periods, $t=0, 1, 2$, and Mark uses recursive utility with $\delta=0.8$ and $\theta=\frac12$: $$U_t = \left((1-\delta)\, u_t^{\theta} + \delta\, U_{t+1}^{\theta}\right)^{1/\theta} \quad\text{for }t=0,1,2 \quad\text{and}\quad U_3=0.$$

  1. Write the expression for $U_2$ as a function of $c_2$ and $U_3$.
  2. Write the expression for $U_1$ as a function of $c_1$ and $U_2$.
  3. Write the expression for $U_0$ as a function of $c_0$ and $U_1$.
  4. Remember that $c^\ast_2(k_2)=k_2$. Apply Recipe #0 to $U_1$ to find $c^\ast_1(k_1)$.

Recipe #2

The setting is identical to the previous problem. Consider Mark Watney's problem in period $t=2$: choose $c_2$ to maximize $U_2$ subject to $0\le c_2$ and $c_2\le k_2$. Using Recipe #2:

  1. Write the corresponding Lagrangian.
  2. Write down the table of all possible cases for $(\lambda_1,\lambda_2)$.
  3. For each case: write the corresponding FOCs (not complementary slackness conditions nor constraints).
  4. For each case, determine whether the FOCs admit a solution, and if so, solve for it.
  5. Verify that the case $\lambda_1=0$, $\lambda_2\gt 0$ satisfies all the remaining Recipe #2 conditions and is therefore the solution.

Nash Equilibrium

Read PS 02—the setting is identical, but with two agents instead of three.

  1. Use Recipe #2 to obtain each agent's best response. Hint: Write $\mathrm{BR}_i$ as a piecewise function: for some values of $g_{-i}$, $\mathrm{BR}_i(g_{-i})$ is the corner solution $g_i=0$.
  2. Assuming $w_1\gt w_2$, find the Nash equilibrium of this game. Hint: Watch out for corner solutions again! You must consider two possible scenarios: when $w_1$ and $w_2$ are “close” or “far apart.”

Efficiency

The setting is as in the previous problem. Consider the welfare function $W(\alpha)=\alpha\, u_1+(1-\alpha)\, u_2$ with $0\lt\alpha\lt 1$.

  1. Use Recipe #0 and obtain the corresponding FOCs with respect to $g_1$ and $g_2$.
  2. Assuming that the Nash equilibrium in the previous section is interior ($g_1\gt 0$ and $g_2\gt 0$), and using the Nash equilibrium FOCs together with the welfare function FOCs, show that the Nash equilibrium is not efficient.
  3. When $w_1=w_2$ and $\alpha=\tfrac12$, what is the Nash equilibrium level of the public good $G$?
  4. When $w_1=w_2$ and $\alpha=\tfrac12$, what is the level of the public good $G$ when the welfare function is maximized?

Recursive Methods

Same setting as the Mark Watney PS (exponential discounting), but assume an infinite horizon. Mark maximizes $$\sum_{t=0}^{\infty} \delta^t \sqrt{c_t}, \qquad \delta=0.5,$$ subject to $k_{t+1}=2(k_t-c_t)$ and $k_0=4$.

  1. Write down the recursive equation that the value function must satisfy.
  2. Does the function $V(k)=\sqrt{2k}$ satisfy the recursive equation in (1)?
  3. What is the FOC that the optimal policy must satisfy?
  4. What is the optimal policy?

Repeated Games

Robinson and Friday are stranded on an island. Both have per-period utility $u(c)=\sqrt{c}$. Each period they go fishing, but with different luck. At each period, the joint catch $(r,f)$ is drawn with equal probability $\tfrac14$ from $$(0,0),\ (1,1),\ (1,0),\ (0,1).$$ They follow this social norm: divide the catch equally if everyone has always done that so far or if it is the start of the game; otherwise, each consumes only their own catch.

At each period, they observe the current catch $(r,f)$ and decide whether to share. If both share, each gets $\sqrt{(r+f)/2}$. If at least one agent does not share, payoffs are $u_R=\sqrt{r}$ and $u_F=\sqrt{f}$.

Notice that the state will reflect both the current catch and the status of their relationship—cooperative or defection phases.

  1. Write the value function equation at each state.
  2. Solve this system of equations. Hint: taking expectations over the catch in each phase collapses the system into one equation per phase. That is, use $\bar V_R^{\text{coop}} = \mathbb E[V_R(\cdot;\text{coop})]$ and $\bar V_R^{\text{def}} = \mathbb E[V_R(\cdot;\text{def})]$.
  3. At the state $\bigl((1,0),\text{cooperative}\bigr)$, by the one-shot deviation principle, which inequality must be satisfied so that Robinson is willing to share his catch?
